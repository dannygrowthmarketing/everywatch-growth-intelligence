## The Calibre

Five complications, one movement. Each part mapped to a growth function — none redundant, all measurable:

1. **Mainspring** — Organic / SEO (the stored energy)
2. **Going train** — Paid / SEM + Social (where stored energy is transmitted)
3. **Escapement** — Conversion / CRO (the regulator of release)
4. **Power reserve** — Lifecycle / CRM (what the engagement holds in reserve)
5. **Regulator** — Analytics / Looker (the fine adjustment)

The case-back view is set out in **Folio II** of the catalogue.
